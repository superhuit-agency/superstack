# Superstack

## Wordpress

### Installation

```bash
    cd wordpress
    npm install
    composer config http-basic.release-belt.superhuit.ch [USERNAME] [PASSWORD]
    composer config http-basic.connect.advancedcustomfields.com [USERNAME] [PASSWORD]
    npm run start
```

### Development

```bash
    npm run dev
```

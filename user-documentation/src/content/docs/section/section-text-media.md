Cette section présente une **image** d'un côté et du contenu de l'autre :

- une **image**
- un **surtitre**, un **titre** et un ou plusieurs **paragraphes**
- **deux boutons** d'action
- le tout sur un **fond de couleur**, avec des étiquettes décoratives en option

Mobile : l'image et le texte passent automatiquement l'un sous l'autre.

## Insertion

bouton **+** → onglet **Compositions** → catégorie **Sections with media** → choisissez **Section text + média**.

![Insertion via le panneau Compositions](/docs/section/section-text-media/insertion.png)

## Édition pas à pas

### Image

1. **Cliquez n'importe où dans le bloc média + texte** pour le sélectionner — sa barre d'outils apparaît, avec le bouton **Replace** et deux boutons pour choisir le côté de l'image (**Show media on left** / **Show media on right**).

    ![Sélection du bloc média + texte](/docs/section/section-text-media/01-select-image.png)

2. **Cliquez sur « Replace »** — choisissez **Open Media Library**, **Upload**, **Use featured image**, ou **Reset**.

    ![Menu Replace](/docs/section/section-text-media/02-replace-menu.png)

3. **« Open Media Library »** : la médiathèque s'ouvre — sélectionnez un fichier puis **Select**.

    ![Médiathèque](/docs/section/section-text-media/03-media-library.png)

### Textes

4. **Modifiez le surtitre, le titre et les paragraphes** — cliquez directement dessus et tapez ; **gras**, _italique_ et liens sont dans la barre flottante.

    ![Édition des textes](/docs/section/section-text-media/04-edit-texts.png)

### Boutons

5. **Modifiez un bouton** — cliquez dessus pour changer son texte ; le lien se règle avec l'icône 🔗.

    ![Sélection d'un bouton](/docs/section/section-text-media/05-select-button.png)

    ![Réglage du lien du bouton](/docs/section/section-text-media/06-button-link.png)

6. **Choisissez le style d'un bouton** — colonne de droite, onglet **Styles** : **Primary** (noir plein), **Secondary** (contour) ou **Link**.

    ![Styles de bouton](/docs/section/section-text-media/07-button-styles.png)

### Fond et étiquettes

7. **Changez le fond de la section** — sélectionnez la section (fil d'Ariane _Section_ en bas), puis panneau **Section background** → **Background color** : blanc ou beige.

    ![Panneaux Section background et Section tags](/docs/section/section-text-media/08-section-background.png)

8. **Réglez les étiquettes** — panneau **Section tags** → **Number of tags** : 0 ou 2 pastilles ; le texte se tape directement dessus.

    ![Panneau Section tags](/docs/section/section-text-media/09-section-tags-panel.png)

    ![Étiquettes éditables dans le canvas](/docs/section/section-text-media/10-section-tags-canvas.png)

## À noter

- **Fond** : seulement **blanc** ou **beige** — pas les autres couleurs disponibles sur d'autres sections.
- **Étiquettes** : 0 ou 2 uniquement (pas 1), 16 caractères max, sans réglage d'inclinaison (position fixe).
- **Boutons** : seulement 3 styles disponibles ici — **Primary**, **Secondary**, **Link** (pas de Tertiary).
- Le bloc média + texte n'est **pas verrouillé** : le bouton **Replace** et la bascule gauche/droite de l'image restent toujours accessibles depuis sa barre d'outils.

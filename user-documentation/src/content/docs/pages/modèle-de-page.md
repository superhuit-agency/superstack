À la création d'une nouvelle page, WordPress propose de partir d'un **modèle de page complet** plutôt que d'une page vide : une fenêtre « Choisir une composition » s'ouvre automatiquement.

## Les différents type de modèle de page

<table>
  <thead>
    <tr><th>Catégorie</th><th>Modèle</th><th>Description</th></tr>
  </thead>
  <tbody>
    <tr>
      <td rowspan="4">Page</td>
      <td>Page d'accueil</td>
      <td>Affiche la page d'accueil de votre site, que celle-ci soit paramétrée pour afficher les derniers articles ou une page statique. Le modèle de page d'accueil prend le pas sur tous les autres modèles.</td>
    </tr>
    <tr>
      <td>Page</td>
      <td>Affiche une page statique à moins qu'un modèle personnalisé ait été appliqué à cette page ou qu'un modèle dédié n'existe.</td>
    </tr>
    <tr>
      <td>Page 404</td>
      <td>S'affiche quand un internaute visite une page qui n'existe pas, en suivant un lien mort ou en faisant une erreur dans l'URL.</td>
    </tr>
    <tr>
      <td>Index</td>
      <td>Utilisé comme modèle par défaut pour toutes les pages lorsque aucun modèle plus précis n'a été défini.</td>
    </tr>
    <tr>
      <td rowspan="2">Blog</td>
      <td>Page d'accueil blog</td>
      <td>Affiche les derniers articles sur la page définie comme étant votre page d'accueil du blog dans les réglages de lecture. S'il existe, le modèle de page d'accueil prend le pas sur ce modèle lorsque les articles sont affichés sur la page d'accueil.</td>
    </tr>
    <tr>
      <td>Publication seule</td>
      <td>Affiche une publication unique sur votre site à moins qu'un modèle personnalisé ait été appliqué à cette publication ou qu'un modèle dédié n'existe.</td>
    </tr>
  </tbody>
</table>

## Édition pas à pas

### Comment modifier un modèle de page

<div style="padding:16px; background-color:var(--color-second-orange-100);border-radius:24px; display: flex; gap: 16px;">
    <span style="font-size:20px">⚠️</span> 
    <span>Les modifications dans un modèle ne sont pas refléter automatiquement sur le site pour le moment et nécéssite une étape de déploiement de la part de Superhuit</span>
</div>

1. **Accéder aux modèles**: depuis le menu principal, rendez-vous dans Apparence > Éditeur puis sélectionner Modèle. Vous accéderez à la liste des modèles disponible.
   ![Menu modèle de page](/docs/pages/theme-de-page/04-model-access.png)

2.**Sélectionner le modèle à modifier**
Pour en savoir plus : [Comprendre les différents type de modèle](/pages/themes-de-page/#comment-modifier-un-mod%C3%A8le-de-page)

3.**Modifier le modèle comme une page**

## À noter

- La case **« Toujours afficher les compositions de démarrage pour les nouvelles pages »** en bas de la fenêtre contrôle son affichage : ne la décochez pas, sinon les nouvelles pages arriveront vides (réactivable dans les préférences de l'éditeur).

À la création d'une nouvelle page, WordPress propose de partir d'un **modèle de page complet** plutôt que d'une page vide : une fenêtre « Choisir une composition » s'ouvre automatiquement.

## Édition pas à pas

1. **Créez une nouvelle page** — **Pages → Ajouter une page** : la fenêtre « Choisir une composition » s'ouvre avec les modèles disponibles.

    ![Fenêtre Choisir une composition à la création d'une page](/docs/pages/themes-de-page/01-new-page.png)

2. **Cliquez sur le modèle** — la page se remplit avec toutes ses sections pré-assemblées ; il ne reste qu'à remplacer les textes et images d'exemple.

    ![Page remplie avec le modèle choisi](/docs/pages/themes-de-page/02-choose-template.png)

3. **Ou partez de zéro** — fermez la fenêtre (croix) pour obtenir une page vierge ; vous pouvez toujours insérer les sections une à une via le bouton **+** → onglet **Compositions**.

    ![Page vierge après fermeture de la fenêtre](/docs/pages/themes-de-page/03-blank-page.png)

## À noter

- La case **« Toujours afficher les compositions de démarrage pour les nouvelles pages »** en bas de la fenêtre contrôle son affichage : ne la décochez pas, sinon les nouvelles pages arriveront vides (réactivable dans les préférences de l'éditeur).

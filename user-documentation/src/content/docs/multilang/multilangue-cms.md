L'interface wordpress est par défaut en français. Certaines chaîne de caractères peuvent apparaître non traduite, voici comment les traduire.

## Édition pas à pas

1. **Les langues du site** se gèrent dans **Langues** — le menu latéral _Langues_ liste les langues actives ; l'étoile marque la langue par défaut.

2. **Les petites chaînes d'interface** se traduisent dans **Langues → Traductions** — titre/description du site et libellés du site (« Previous », « Next », « See all »…, groupe « superstack ») : une case par langue, sans toucher aux pages.
